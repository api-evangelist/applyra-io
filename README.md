Applyra is an App Store Optimization (ASO) platform designed for indie developers, solo founders, and small mobile studios. It offers AI‑powered keyword tracking, competitor analysis, and metadata suggestions for both the Apple App Store and Google Play. Founded in 2025 by Aurélien Weiss, Applyra provides a free tier and affordable paid plans, serving over 7,000 apps and tracking more than 150,000 keywords. The service includes daily ranking updates, keyword discovery, and tools to monitor and improve app visibility, all through an intuitive dashboard.

**Areas:** ASO · Mobile · Analytics · AI · Indie

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Applyra: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
